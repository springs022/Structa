# Structa tests

`test_*.py` は自動回帰テストです。プロジェクト直下で次を実行します。

```text
python -m unittest discover -s test -v
```

`manual/` は、以前からある結果目視用・旧 API 用の調査スクリプトです。
自動テストとしては実行されません。旧 API の資料として残しています。

高速化時は、少なくとも以下を守ることを確認します。

- 盤座標と持駒変換が変わらないこと
- 駒別の最小移動コストが変わらないこと
- 既知の解の途中局面を必要手数計算が誤って枝刈りしないこと
- 短い既知問題で実際に解が検出されること
